# frontend — Uniswap V2–style DEX dApp (Next.js 15)

Web frontend for the [Uniswap V2–style DEX](../README.md): swap, add/remove liquidity,
and a portfolio view backed by on-chain TWAP-only prices.

- **Stack** — Next.js 15 (App Router), React 19, TypeScript strict, ethers v6,
  @tanstack/react-query, Tailwind + shadcn/ui.
- **Pages** — `/swap`, `/liquidity`, `/portfolio`, `/debug`; server-side RPC reads via
  `api/reserves/route.ts`, client writes via MetaMask (BrowserProvider).
- **Bindings** — `src/lib/contracts/` is generated by `scripts/sync-deploy.ts` from
  Foundry broadcast files — never hand-edit.
- **Tests** — Vitest + Testing Library unit/component tests (`tests/unit/`); Playwright
  e2e (`npm run test:e2e`).

## Usage

The dApp needs the local anvil chain running with contracts deployed. From the repo
root, `./scripts/dev-deploy.sh --dev` does everything (fresh anvil → deploy → sync →
dev server on http://localhost:3000). Manual flow:

```shell
npm install
npm run dev   # http://localhost:3000 (anvil must be running)
```

```shell
npm run test         # Vitest unit/component tests
npm run lint         # ESLint
npx tsc --noEmit     # TypeScript strict check
npm run build        # Next.js production build
npm run test:e2e     # Playwright e2e (auto-starts dev server)
```

Connect MetaMask to chainId 31337 (RPC `http://127.0.0.1:8545`) and import the anvil
deployer key `0xac0974…ff80` (see `../scripts/dev-deploy.sh`).

## Sepolia / Vercel deployment

The public demo deploys the contracts on Sepolia (chainId 11155111) and hosts this
frontend on Vercel:

- **Vercel Root Directory: `frontend/`** — import the repo, set the env var
  `SEPOLIA_RPC_URL` for Production + Preview (framework auto-detected: Next.js).
- **Env vars are server-only** — `SEPOLIA_RPC_URL` is read by the
  `api/reserves/route.ts` handler (via `createServerProvider()`); never prefix it
  with `NEXT_PUBLIC_`, the client never depends on any env var.

Full step-by-step guide (6 steps, ≤ 30 min, with time budgets) and the env var
table: see the "Sepolia Testnet / Vercel Deployment" section in
[../README.md](../README.md) (English mirror: [../README.en.md](../README.en.md)).
